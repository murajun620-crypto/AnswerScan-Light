# AnswerScan Light

ブラウザーだけで、学籍番号と数値解答の読み取り結果を目視確認するアプリです。

**公開ページ:** https://murajun620-crypto.github.io/AnswerScan-Light/

## 使い方

1. 担当者がAnswerScanで「ファイル → AnswerScan Light用フォルダーを書き出す…」を実行します。氏名を黒塗りにしたPDFと、確認用画像・名簿・読み取り結果をまとめます。
2. 秘書は公開ページをEdgeかChromeで開き、「確認用フォルダーを開く」で、受け取った`Light_日付-時刻-ID`フォルダーを選びます。フォルダーへの読み書きは、ブラウザーの許可画面で許可してください。
3. 学籍番号と解答を画像と比較して、確認または保留を選びます。Enterでも確認できます。
4. 「確認結果を保存」で`checked_<ID>.answerscan-project.json`をHTMLと同じフォルダーに直接保存します。元の`review_<ID>.answerscan-project.json`は残し、2回目以降は同じ確認結果ファイルを更新します。フォルダー全体を担当者へ返します。
5. 担当者はAnswerScanで返却JSONを開き、必要なら保留を再確認してExcelを出力します。

途中から再開する場合は、同じ確認用フォルダーを開いた後、「途中の確認を開く」で最後に保存したJSONを選びます。未保存の変更があると、閉じる・再読み込み時にブラウザーの警告を表示します。保存のキャンセル・失敗後も警告を維持します。警告の文言はブラウザー標準です。こまめに保存してください。

受け取った`review_<ID>.html`を直接開けば、オフラインでも使えます。この場合は最初の保存時に、HTMLが入ったフォルダーを選びます。旧版の`review.html`も読み込めます。同じフォルダーへの書き込みに対応したEdgeまたはChromeを使ってください。OCR・認識モデル・Pythonのインストールは不要です。

## データの扱い

- 公開されているのは、データの入っていないアプリ本体と説明書だけです。
- 公開ページを開くための通信はありますが、選んだ確認用ファイルはブラウザー内で読み取ります。答案画像・学籍番号・名簿・確認結果をサーバーに送信する機能はありません。
- 確認用HTML内のデータ部分だけを読み取り、そのHTML内のスクリプトは実行しません。画像はファイル内の画像データに限定し、外部URLを拒否します。
- 外部API、アクセス解析、CDN、ブラウザーの永続ストレージ、ローカルサーバーは使用しません。
- 確認用HTML、PDF、確認結果JSONは個人情報を含みます。GitHubへ公開したり、ChatGPTへ添付したりしないでください。

このリポジトリの`index.html`に、画面・CSS・JavaScriptの本体を同梱しています。確認作業専用で、OCR・採点設定の変更・Excel出力は担当者のAnswerScanで行います。
