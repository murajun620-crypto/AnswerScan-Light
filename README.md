# AnswerScan Light

ブラウザーだけで、学籍番号と数値解答の読み取り結果を目視確認するアプリです。

**公開ページ:** https://murajun620-crypto.github.io/AnswerScan-Light/

タイトル横とブラウザータブにバージョン番号を表示します。公開ページは再読み込みで最新版が表示されます。受け取ったHTMLを直接開く場合は、そのHTMLが書き出された時点のバージョンです。

## 使い方

1. 担当者がAnswerScanで「ファイル → AnswerScan Light用HTMLを書き出す…」を実行します。`元PDF名.ASL_review.html`を1つ作り、秘書へ渡します。専用フォルダー・PDF・元JSONは不要です。氏名を黒塗りにした画像、学籍番号の名簿、読み取り結果はHTML内に入っています。
2. 秘書は公開ページをEdgeかChromeで開き、「確認用ファイルを開く」でHTMLを選びます。HTMLを直接開けばオフラインでも使えます。
3. 学籍番号と解答を画像と比較して、確認または保留を選びます。Enterでも確認できます。
4. 「確認結果を保存」で、ファイル名を入力済みの保存画面を開きます。HTMLと同じフォルダーを選んで保存してください。初回だけ保存先を選び、2回目以降は同じファイルを更新します。「確認用フォルダーを開く」から開いた場合は、そのフォルダーへ直接保存します。
5. 保存した`checked_<ID>.answerscan-project.json`だけを担当者へ返します。担当者はAnswerScanで返却JSONを開き、元PDFを照合して、必要なら保留を再確認しExcelを出力します。元PDFが見つからなければ選択してください。別のPDFは拒否します。

途中から再開する場合は、HTMLを開いた後、「途中の確認を開く」で最後に保存したJSONを選びます。未保存の変更があると、閉じる・再読み込み時にブラウザーの警告を表示します。保存のキャンセル・失敗後も警告を維持します。こまめに保存してください。

旧版の`review_<ID>.html`や`review.html`も読み込めます。旧版の返却JSONは黒塗りPDFを参照するため、旧フォルダーを保管して使用してください。新しい単一HTMLはファイルを別フォルダーへ移しても動きます。EdgeまたはChromeを使ってください。OCR・認識モデル・Pythonのインストールは不要です。

## データの扱い

- 公開されているのは、データの入っていないアプリ本体と説明書だけです。
- 公開ページを開くための通信はありますが、選んだ確認用ファイルはブラウザー内で読み取ります。答案画像・学籍番号・名簿・確認結果をサーバーに送信する機能はありません。
- 確認用HTML内のデータ部分だけを読み取り、そのHTML内のスクリプトは実行しません。画像はファイル内の画像データに限定し、外部URLを拒否します。
- 外部API、アクセス解析、CDN、ブラウザーの永続ストレージ、ローカルサーバーは使用しません。
- 確認用HTML、PDF、確認結果JSONは個人情報を含みます。GitHubへ公開したり、ChatGPTへ添付したりしないでください。

このリポジトリの`index.html`に、画面・CSS・JavaScriptの本体を同梱しています。確認作業専用で、OCR・採点設定の変更・Excel出力は担当者のAnswerScanで行います。
